# Site web d'auto-école

Site web de gestion pour une auto-école permettant d'administrer les élèves, les thèmes d'apprentissage, les séances de code/conduite et les évaluations.

* **Gestion des élèves** : Ajout, consultation des fiches et suivi des dossiers.
* **Gestion des thèmes et séances** : Création de thèmes et planification de séances.
* **Inscriptions** : Inscription des élèves aux différentes séances prévues.
* **Évaluation et notes** : Saisie et suivi des notes obtenues par les élèves.
